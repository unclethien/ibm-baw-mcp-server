Your organization has invested years building business workflows in IBM Business Automation Workflow. The BAW MCP Server makes every one of those workflows instantly accessible to AI agents — through natural language, with no additional API development, no custom connectors, and no changes to your existing BAW applications.

What It Does

The BAW MCP Server is a bridge between AI agents and your BAW environment. It automatically discovers every exposed REST service in your BAW installation at startup and publishes them as AI-callable tools — ready for any MCP-compatible agent to invoke by description, not by API signature.

Customer Story — BCBSTN POC Context

Blue Cross Blue Shield of Tennessee · POC Scenario

Provider Enrollment via AI Agent

BCBSTN operates a large-scale Provider Enrollment workflow in BAW. Today, specialists fill out multi-step Heritage Coach forms manually — provider details, specialty, license, address — one task at a time.

With the BAW MCP Server and watsonx Orchestrate, an enrollment specialist could instead say:

"Enroll Dr. John Smith, NPI 1234567890, Internal Medicine, license TN MD-12345 expiring June 2027, practice at 123 Medical Center Drive Nashville TN 37203."

The AI calls the ProvEnrl_SubmitEnrollment MCP tool, fills all parameters from the natural language input, and submits the BAW workflow — in seconds, with no form.

Getting Started

Open source under Apache 2.0, available on GitHub. Fastest path to a running demo:

  1. Install: uvx --from git+https://github.com/ibmbpm/ibm-baw-mcp-server ibm-baw-mcp-server
  2. Set environment variables: ENDPOINT, USERID, PASSWORD
  3. Register as a toolkit in watsonx Orchestrate
  4. Any BAW exposed REST service is now an AI tool — no further configuration required

For demos without a live BAW environment, a mock server can simulate the exposed services endpoint locally in minutes.
