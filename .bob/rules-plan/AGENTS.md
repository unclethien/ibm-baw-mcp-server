# Plan Mode Architecture Rules (Non-Obvious Only)

- **Dynamic tool registration**: MCP tools are not defined in Python — they are generated at server start from OpenAPI specs fetched live from BAW. Any feature touching tool definitions must account for startup failures (network down, bad credentials) being non-fatal per-spec (logged + `continue`), not fatal to the whole server.
- **Transport is a startup concern**: transport mode (`stdio`/`http`/`sse`/`streamable-http`) is chosen at CLI invocation and cannot be changed at runtime. Plans that involve transport switching require a server restart.
- **`DirectOpenAPIProvider` is the only implementation** of the abstract `OpenAPIProvider`. Adding alternative providers (e.g., for cached specs) requires subclassing `OpenAPIProvider` and wiring via `WorkflowClient.__init__`.
- **No persistent state between requests**: `BaseHTTPClient` and `WorkflowClient` are instantiated once at server start via `initialize_workflow_client()`. CSRF token state lives in `DirectOpenAPIProvider` — it refreshes automatically but is not shared across multiple server processes.
- **`uv` is the required package manager**: `requirements.txt` is auto-generated by `uv export` and must not be hand-edited. Lock changes go through `uv lock` + `uv export`.
- **mypy + ruff are both required** for any PR. `disallow_untyped_defs = true` means all new functions need full annotations including return types.
